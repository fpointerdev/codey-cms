# CodeY CMS agent guide

CodeY CMS is the self-hosted runtime for editable websites generated by CodeY or another compatible agent.

Before generating or changing a site:

1. Read `docs/generated-site-contract.md`.
2. Read the authenticated `GET /api/v1/config/generation/contract` endpoint when operating an installed CMS.
3. Use only generator-safe elements from the returned builder registry.
4. Validate, dry-run, and atomically apply the same WebsiteSpec 1.0 payload.
5. Verify the public server-rendered HTML and complete browser interactions before claiming they work.

Preserve the existing framework, authentication, permissions, migrations, signed update path, and customer-owned provider settings. Never put platform secrets, customer credentials, generated private data, or trusted-editor custom code in WebsiteSpec.

The read-only discovery connector is documented in `docs/ai-agent-integration.md`.
