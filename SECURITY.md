# Security Policy

## Supported versions

Security fixes are provided for the latest stable CodeY CMS release. Update to the
latest signed release before reporting behavior that may already be fixed.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
vulnerability reporting form:

https://github.com/fpointerdev/codey-cms/security/advisories/new

Include the affected version, deployment method, reproduction steps, expected
impact, and any relevant logs with credentials and personal data removed. You
should receive an acknowledgement within three business days. We will coordinate
validation, remediation, and disclosure through the private advisory.

## Deployment responsibility

CodeY CMS protects application-level access, signed updates, and stored provider
credentials. Operators remain responsible for host security, TLS termination,
database access, off-host backups, and installing supported stable releases.
