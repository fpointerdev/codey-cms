# CodeY CMS support

CodeY CMS is a community-supported, self-hosted project.

- Ask setup and usage questions through the [support issue form](https://github.com/fpointerdev/codey-cms/issues/new?template=support-question.yml).
- Report a reproducible defect with the bug-report issue form.
- Propose declarative extensions with the extension-proposal issue form.
- Report security vulnerabilities privately as described in `SECURITY.md`.

Include the CMS version, installation method, deployment profile, and relevant logs with secrets removed. Do not post customer data, credentials, backup archives, access tokens, payment details, or private WebsiteSpec content.
