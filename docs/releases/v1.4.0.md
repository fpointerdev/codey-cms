# CodeY CMS 1.4.0

CodeY CMS 1.4.0 improves visual editing, shop operations, signed-in account
security, and the deterministic integration surface used by CodeY and other AI
agents.

## Changes

- Adds the generation automation `1.0` contract for authenticated discovery,
  validation, dry runs, and atomic WebsiteSpec application.
- Publishes the read-only CodeY CMS MCP integration and AI-agent discovery
  guidance without exposing CMS credentials or internal generation prompts.
- Adds full and partial admin refunds, idempotent Stripe and PayPal provider
  handling, buyer refund requests, order history, notifications, exports, and
  anonymization-safe refund records.
- Adds signed-in device and session controls with recent-authentication checks
  for sensitive actions.
- Simplifies dashboard, editor-mode, catalog, and shop administration workflows.
- Adds bounded parallax and staggered entrance effects with reduced-motion
  support, two procedural Three.js scene presets, editable scene accent colors,
  and matching public and builder-preview runtimes.
- Replaces video poster URL entry with an upload-first preview and removal flow.
- Bundles public and admin styles deterministically and verifies generated
  browser assets before validation and release.

## Compatibility

- WebsiteSpec remains at version `1.0`.
- Exported-site acceptance remains at version `1.0`.
- The builder contract remains at version `1.0`.
- The builder registry remains at `2026-08-26.2`; the new visual options are
  additive and older saved content continues to render.
- Signed stable resolution and signature enforcement are unchanged.

## Database And Environment

Two migrations add durable provider refund records and buyer refund requests:

- `20260902000000_payment_refunds`
- `20260902010000_buyer_refund_requests`

The packaged updater applies both migrations automatically. No new environment
variable is required. Payment, email, and storage credentials remain managed by
administrators through encrypted database-backed settings.

## Upgrade Notes

Create a verified backup, then update through the signed stable release path.
The release qualifier verifies installation, the previous-stable upgrade and
rollback path, WebsiteSpec import, admin login and editing, restart persistence,
public server rendering, and encrypted backup restoration against the extracted
self-host package.
