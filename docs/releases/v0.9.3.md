# CodeY CMS 0.9.3

CodeY CMS 0.9.3 hardens production diagnostics, disaster recovery, and the
signed self-host release supply chain without changing the WebsiteSpec or
exported-site acceptance contracts.

## Highlights

- Keeps public liveness and readiness responses intentionally minimal.
- Requires `manage:modules` access for detailed runtime diagnostics and metrics.
- Separates traffic readiness from backup protection so first setup stays simple.
- Shows owners when backups are local-only and requires an explicit, successful
  off-site mirror before reporting disaster-recovery protection.
- Pins Node.js and PostgreSQL container inputs to immutable multi-architecture
  SHA-256 digests.
- Publishes a CycloneDX 1.6 production-dependency SBOM whose checksum, source
  commit, and container references are covered by the signed release manifest.

## Upgrade Notes

Existing sites remain compatible and update automatically from the signed stable
feed. Public health monitors should continue using `/api/v1/health/ready` and
read only `data.status`. Operators must authenticate to use
`/api/v1/health/diagnostics` or `/api/v1/health/metrics`.

Self-hosted sites start encrypted local backups automatically. Before production
handoff, place the mirror on independent storage, test restoration, and set
`BACKUP_OFFSITE_PROTECTED=true`.
