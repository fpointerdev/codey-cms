# CodeY CMS 0.9.1

CodeY CMS 0.9.1 improves parity between a website generated in UseCodeY and
the same website running in the downloadable, self-hosted CMS.

## Highlights

- Preserves the generated Experience DNA and its sanitized runtime stylesheet
  when importing a WebsiteSpec.
- Renders generated sections with the same structural hooks used by the
  platform preview, including richer hero, collection, gallery, feature, and
  contact layouts.
- Supports full-bleed hero background media with safe overlay, opacity, focal
  position, and responsive behavior.
- Keeps generated branding, navigation state, section motion, and reduced
  motion behavior consistent in the public CMS renderer.
- Preserves generated site titles and homepage content during first-run
  installation instead of replacing them with starter content.
- Extends generated contact forms with subject fields and configurable button
  labels.
- Adds focused WebsiteSpec, rendering, design-system, installation, and CSS
  sanitization coverage for the updated runtime contract.

## Distribution

This release is licensed under `GPL-2.0-or-later`. The downloadable ZIP and
runtime archive include the complete license, CodeY legal notice, source code,
installation scripts, and reproducible package lockfile.

## Installation

Install Docker Desktop, download `codey-cms-0.9.1.zip`, extract it, and run
`start-codey.cmd` on Windows or `./start-codey.sh` on macOS and Linux. Complete
the one-time setup page opened by the launcher.

## Upgrade Notes

Existing CodeY CMS installations can install this release through the signed
stable update flow. The updater verifies the manifest and artifact checksum,
creates a backup, performs readiness checks, and restores the previous runtime
if the update cannot start safely.
