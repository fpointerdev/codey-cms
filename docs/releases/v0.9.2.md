# CodeY CMS 0.9.2

CodeY CMS 0.9.2 hardens the handoff from CodeY generation to a downloadable,
self-hosted website.

## Highlights

- Applies every generated WebsiteSpec as one database transaction.
- Adds deterministic headless support to the packaged root launchers.
- Qualifies a signed stable ZIP through installation, generated content import,
  owner login, CMS editing, restart, and public server rendering.
- Emits a machine-readable exported-site acceptance report for CodeY platform
  release gates.
- Keeps encrypted backup and restore qualification in the same end-to-end path.
- Advertises exported-site acceptance contract version `1.0` in signed release
  metadata.

## Distribution

This release is licensed under `GPL-2.0-or-later`. The downloadable ZIP and
runtime archive include the complete license, CodeY legal notice, source code,
installation scripts, and reproducible package lockfile.

## Installation

Install Docker Desktop, download `codey-cms-0.9.2.zip`, extract it, and run
`start-codey.cmd` on Windows or `./start-codey.sh` on macOS and Linux. Complete
the one-time owner setup opened by the launcher.

## Upgrade Notes

CodeY should select this release from the signed stable feed automatically.
Existing self-hosted installations can use the signed runtime updater, which
creates a backup and rolls back if the new runtime cannot become ready.
