# CodeY CMS 0.9.4

CodeY CMS 0.9.4 keeps the backend page builder synchronized with changes made
through the visual editor without changing the WebsiteSpec, database, or public
rendering contracts.

## Highlights

- Publishes a page-scoped change marker after successful page mutations.
- Refreshes an open backend builder when its page changes in another tab.
- Keeps locale variants isolated so editing one translation does not refresh
  another translation.
- Retries synchronization after transient API failures and avoids overlapping
  refresh requests.

## Contracts

- `websiteSpec: "1.0"`
- `builder: "1.0"`
- `exportedSiteAcceptance: "1.0"`
- `operationalDiagnostics: "1.0"`
- `offsiteBackupReadiness: "1.0"`
- `supplyChain: "1.0"`

## Upgrade Notes

No migration or new environment setting is required. Existing self-hosted sites
receive the synchronization behavior through the normal signed update flow.
