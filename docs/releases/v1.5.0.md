# CodeY CMS 1.5.0

CodeY CMS 1.5.0 adds owner-managed marketing measurement and search
verification while preserving the simple generated-site workflow and strict
WebsiteSpec boundary.

## Changes

- Adds a focused **Settings > Marketing** workflow for Google Analytics 4,
  Google Tag Manager, Plausible, Meta Pixel, and Google/Bing site verification.
- Stores owner configuration with the site in the database. Generated pages
  inherit it without carrying provider IDs, consent state, or tracking code in
  WebsiteSpec.
- Asks for visitor consent before loading analytics by default and provides a
  persistent privacy control for changing that decision.
- Adds bounded first- and last-touch campaign attribution without storing form
  values, customer identity, cart credentials, order lookup tokens, or payment
  details.
- Emits stable page, lead, and commerce events. Provider-specific ecommerce
  payloads are generated by the CMS, and paid purchase events require the CMS
  provider flow to confirm payment.
- Server-renders Google Search Console and Bing Webmaster Tools verification
  metadata without requiring custom code.
- Adds a dedicated support issue form and documents the public marketing event
  and generator-safety contracts.
- Audits the production-pruned dependency lockfile so release security gates
  cover shipped packages without suppressing developer-tool advisories.
- Updates Nodemailer to 9.1.1, Playwright to 1.63.0, Motion to 13.2.0, and
  TypeScript ESLint to 8.69.0, including the rebuilt Motion browser runtime.

## Compatibility

- WebsiteSpec remains at version `1.0`.
- Exported-site acceptance remains at version `1.0`.
- The builder contract and registry versions are unchanged.
- Existing pages, products, custom storefronts, provider settings, and signed
  update behavior remain compatible.
- Marketing settings are owner-managed and must not be written by CodeY or
  another generator during WebsiteSpec import.

## Database And Environment

No database migration or new environment variable is required. Marketing
settings use the existing site settings record. Payment, email, storage, and
marketing configuration remain customer-owned and managed from the dashboard.

## Upgrade Notes

Create a verified backup, then update through the signed stable release path.
The packaged updater applies the release without resetting site content or
owner settings. The release qualifier verifies a fresh installation, previous
stable upgrade and rollback, WebsiteSpec import, admin editing, restart
persistence, public server rendering, and encrypted backup restoration against
the extracted self-host package.
