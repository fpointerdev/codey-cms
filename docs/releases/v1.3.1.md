# CodeY CMS 1.3.1

CodeY CMS 1.3.1 is a maintenance release that keeps the supported development
toolchain current after the 1.3.0 premium visual runtime release.

## Changes

- Updates the Nodemailer type definitions from 6.4.22 to 6.4.24.
- Retains the dependency update policy that groups compatible patch and minor
  updates while deferring unsupported major upgrades for explicit migration.

## Compatibility

- WebsiteSpec remains at version `1.0`.
- Exported-site acceptance remains at version `1.0`.
- The builder registry remains at `2026-08-26.2`.
- Runtime behavior and public rendering are unchanged from 1.3.0.

## Database And Environment

No database migration or new environment variable is required.

## Upgrade Notes

Create a verified backup, then update through the signed stable release path.
The release qualifier verifies installation, upgrade and rollback, WebsiteSpec
import, admin editing, restart, public server rendering, and encrypted backup
restore against the downloadable package.
