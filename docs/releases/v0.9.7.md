# CodeY CMS 0.9.7

CodeY CMS 0.9.7 closes the remaining release, recovery, notification, and
customer-data hardening gaps before 1.0 while preserving the simple self-host
installation and dashboard-owned provider configuration model.

## Highlights

- Makes order email delivery concurrency-safe with automatic bounded retries,
  stale-worker recovery, and a simple manual retry action.
- Adds owner-only customer data export and irreversible anonymization while
  preserving financial totals, order history, and tamper-evident audit records.
- Qualifies the extracted self-host ZIP on normal CI and proves real
  previous-stable updates plus forced-failure database rollback before release.
- Moves Corepack and pnpm update state onto the persistent writable runtime
  volume and declares the automatic-update bootstrap version in signed metadata.
- Restores encrypted backups into a separate database and media directory during
  integration testing.
- Expands the generated OpenAPI contract with authentication, permissions, path
  parameters, response envelopes, and authoritative Zod validator references.
- Adds CodeQL, dependency review, Dependabot, CODEOWNERS, private vulnerability
  reporting guidance, protected release approval, and main-branch tag checks.
- Pins Alpine runtime packages and binds the dependency lockfile, images, and
  package versions into the signed CycloneDX SBOM provenance.

## Provider Configuration

Stripe, PayPal, Resend, Postmark, and generic HTTPS email settings remain owned
by each site administrator. Credentials are entered in the dashboard, encrypted
in the site database, and never returned by configuration APIs.

## Upgrade Notes

This release adds the order notification delivery migration. Packages through
`v0.9.6` must download the latest self-host ZIP and run the root launcher once
to move package-manager state onto the writable runtime volume. Existing named
database, media, backup, and secret volumes are reused; setup is not repeated.
Automatic supervisor updates are qualified from `v0.9.7` onward.
