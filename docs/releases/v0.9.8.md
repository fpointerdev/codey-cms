# CodeY CMS 0.9.8

CodeY CMS 0.9.8 expands the portable builder and completes the essential
website identity settings needed before 1.0, while preserving the simple
self-host installation and the WebsiteSpec 1.0 contract.

## Highlights

- Adds Process Steps, Comparison Table, and Video elements with focused
  Content, Settings, and Style controls and semantic public rendering.
- Preserves generator-safe custom WebsiteSpec elements and their bounded
  structured values through atomic import, restart, and server rendering.
- Adds logo, browser icon, and default social sharing image settings with media
  upload previews, accessible descriptions, and explicit removal controls.
- Uses configured branding in the public header, favicon, Open Graph and
  Twitter fallbacks, and Organization structured data on both server and client
  navigation paths.
- Adds FAQPage structured data for published FAQ elements and keeps public
  content useful without client-side JavaScript.
- Extends media handling for supported video and document uploads and keeps the
  generated OpenAPI inventory aligned with the runtime.

## Compatibility

- WebsiteSpec remains at version `1.0`; no platform contract update is needed.
- Existing CodeY-generated sites and CodeY CMS `v0.9.7` data remain compatible.
- This release does not add a database migration.
- New branding and sharing settings are optional and default safely for
  existing installations.

## Upgrade Notes

Create a verified backup, then install the update from the dashboard or run the
root launcher from the new self-host package. Existing database, media, backup,
secret, and release-history volumes are reused. Setup is not repeated.
