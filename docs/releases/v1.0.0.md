# CodeY CMS 1.0.0

CodeY CMS 1.0.0 completes the first stable self-hosted release with one
consistent section-design workflow across the dashboard builder, visual editor,
generated WebsiteSpec imports, and public server rendering.

## Highlights

- Gives every section the same focused **Layout**, **Style**, and **Advanced**
  controls in both editing surfaces.
- Adds upload-first section backgrounds with media-library reuse, preview,
  positioning, fit, and accessible overlays.
- Adds bounded borders, radius, shadows, colors, responsive layout overrides,
  and desktop/tablet/mobile visibility without requiring custom CSS.
- Server-renders section backgrounds and design settings with safe URLs,
  intrinsic image dimensions, predictable stacking, and responsive visibility.
- Keeps legacy section colors editable by normalizing and synchronizing the old
  dashboard and visual-editor setting shapes.
- Advances the additive builder registry to `2026-08-18.1`: 37 elements, 36
  editor-visible elements, 35 generator-safe elements, and 20 qualified
  patterns.
- Pins pnpm `11.18.0` across local, container, CI, security, and release builds
  so the required dependency license inventory and SBOM are reproducible.

## Compatibility

- WebsiteSpec remains at version `1.0`.
- Exported-site acceptance remains at version `1.0`.
- Existing CodeY-generated sites and CodeY CMS `v0.9.14` data remain compatible.
- Older `style.backgroundColor` and `background.color` values are accepted and
  normalized automatically when a section is edited.
- CodeY can discover the new additive builder registry at runtime. It does not
  need a separate CMS version selector or a WebsiteSpec contract change.

## Database And Environment

This release does not add a database migration or require a new environment
variable. Section design remains bounded page content stored through the
existing CMS page contract. Uploaded background images use the configured CMS
storage provider.

## Upgrade Notes

Create a verified backup, then update through the signed stable release path.
After upgrading, open one existing page in each editor, confirm its section
colors, and publish a page with a background image. The release qualification
must still prove signed install, WebsiteSpec import, admin edit, restart,
server-rendered public output, and backup/restore before publication.
