# CodeY CMS 0.9.0

CodeY CMS 0.9.0 is the first public beta of the free, self-hosted CodeY website
runtime. It combines a focused visual page builder with content, users, media,
localization, shop management, and operational tooling in one downloadable
package.

## Highlights

- Nontechnical Docker-based installation with a protected browser setup flow.
- Visual page editing with reusable sections, responsive previews, history,
  duplicate actions, accessible reordering, and structured design controls.
- Server-rendered public pages, metadata, canonical URLs, structured data,
  sitemaps, localization alternates, and responsive image output.
- User invitations, role-based access, session revocation, and complete user
  administration.
- Product and storefront management with end-user Stripe and PayPal settings.
- Encrypted database and media backups with restore verification and health
  reporting.
- Signed stable updates with checksums, staged installation, readiness checks,
  and automatic recovery to the previous runtime.

## Distribution

This release is licensed under `GPL-2.0-or-later`. The downloadable ZIP and
runtime archive include the complete license, CodeY legal notice, source code,
installation scripts, and reproducible package lockfile.

## Installation

Install Docker Desktop, download `codey-cms-0.9.0.zip`, extract it, and run
`start-codey.cmd` on Windows or `./start-codey.sh` on macOS and Linux. Complete
the one-time setup page opened by the launcher.

## Upgrade Notes

This is the first public release, so there is no earlier public version to
upgrade. Future stable releases will be offered automatically through the
signed update feed. Back up the database, uploads, runtime secrets, and release
history before any manual migration or recovery operation.
