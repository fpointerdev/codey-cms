# CodeY CMS 0.9.6

CodeY CMS 0.9.6 hardens the nontechnical self-host path and makes release
quality measurable across browsers, operating systems, APIs, and public
performance.

## Highlights

- Adds a Settings > Launch checklist for HTTPS, canonical SEO, tested account
  recovery, protected backups, owner two-step verification, persistent media,
  and signed updates.
- Adds dashboard-managed Resend and Postmark presets while retaining the
  generic HTTP email adapter. Provider keys remain encrypted and write-only.
- Adds `--domain www.example.com` to the Windows, macOS, and Linux launchers.
  The packaged, digest-pinned Caddy service obtains and renews HTTPS
  certificates automatically.
- Binds the direct self-host backend port to localhost and trusts exactly one
  proxy hop only when the automatic HTTPS Compose layer is active.
- Expands browser qualification to Chromium, Firefox, and WebKit and adds
  native launcher checks on Ubuntu, macOS, and Windows.
- Adds frontend and runtime-script linting, coverage regression thresholds, a
  generated 161-operation OpenAPI inventory, and a concurrent public load gate.
- Keeps the public crawl and three-run mobile/desktop Lighthouse assertions at
  100 for performance, accessibility, best practices, and SEO.

## Upgrade Notes

No database migration is required. Existing local and reverse-proxy installs
keep their current behavior. Automatic HTTPS is opt-in through `--domain` or
the packaged `docker-compose.public.yml` layer. Existing generic email settings
remain compatible and appear as the generic provider in the dashboard.
