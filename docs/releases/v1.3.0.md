# CodeY CMS 1.3.0

CodeY CMS 1.3.0 adds optional premium motion and accessible 3D content while
keeping public pages server rendered, resilient, and lightweight by default.

## Highlights

- Adds generator-safe `three-scene`, `three-model`, and `three-panorama`
  builder elements with focused editor controls and semantic poster fallbacks.
- Adds three qualified 3D section patterns for product stages, visual stories,
  and panoramic tours.
- Bundles Motion and Three.js reproducibly. Motion remains subtle and respects
  reduced-motion preferences; the Three.js runtime loads only when a 3D scene
  approaches the viewport.
- Adds secure GLB upload validation for self-contained glTF 2.0 models and
  rejects external model resources.
- Advances the builder registry to `2026-08-26.2` with 40 elements and 26
  qualified section patterns.
- Updates compatible production dependencies and keeps CodeQL initialization
  and analysis on the same pinned release.

## Compatibility

- WebsiteSpec remains at version `1.0`.
- Exported-site acceptance remains at version `1.0`.
- Existing generated sites, pages, templates, commerce data, collections, and
  extensions remain compatible.
- The three new 3D element IDs use the existing generator-safe custom element
  payload contract. CodeY should discover them from the signed builder registry
  instead of hardcoding registry counts.
- Sites without 3D content do not download the Three.js runtime.

## Database And Environment

No database migration or new environment variable is required. Existing media,
storage, backup, payment, email, and extension settings continue unchanged.

## Upgrade Notes

Create a verified backup, then update through the signed stable release path.
After upgrading, confirm a generated site can import and server render the new
3D elements, upload a valid self-contained GLB model, restart successfully, and
retain its public fallback content. The signed package qualifier continues to
prove install, WebsiteSpec import, admin login and editing, restart, public SSR,
and encrypted backup/restore from the extracted download.
