# CodeY CMS 0.9.9

CodeY CMS 0.9.9 is the security, commerce-consistency, and maintainability
release before 1.0. It strengthens live storefront behavior without changing
the WebsiteSpec 1.0 generation contract or adding installation choices for end
users.

## Highlights

- Adds atomic inventory reservations with bounded purchase limits, safe expiry,
  idempotent release, reconciliation tooling, and concurrency coverage.
- Adds shared checkout abuse limits and pending-order caps without storing raw
  customer email addresses or IP addresses in limiter records.
- Replaces public order lookup credentials with hashed, timing-safe tokens and
  keeps lookup secrets out of public and administrative order responses.
- Prevents TOTP replay by accepting each verification counter only once.
- Hardens generic email delivery against private endpoints, DNS rebinding,
  redirects, credential rebinding, oversized responses, and stale connection
  tests.
- Serializes email and payment-provider configuration changes so concurrent
  saves cannot restore old credentials or approve a newer configuration with an
  older test result.
- Requires `manage:secrets` and recent authentication for Stripe and PayPal
  configuration and connection tests. Manual-payment instructions continue to
  require only ordinary payment-update permission.
- Reduces the unauthenticated browser runtime configuration to its explicit
  public contract and strengthens media decoding, frame, quota, and cleanup
  limits.
- Adds enforced linting and coverage ratchets for critical authentication,
  order, payment, backup, and runtime-update code.

## Compatibility

- WebsiteSpec remains at version `1.0`; CodeY does not need a contract-version
  change and should continue resolving the latest signed stable release.
- Existing CodeY-generated sites and CodeY CMS `v0.9.8` data remain compatible.
- Dashboard-managed email and payment credentials remain encrypted in the CMS
  database and are never added to WebsiteSpec or generated environment files.
- Existing email settings gain an internal configuration revision lazily on the
  next save or connection test.

## Database Changes

This release adds four forward-only migrations for checkout guardrails,
inventory reservations, secure order lookup, and TOTP replay prevention. The
packaged launcher and Docker runtime apply them automatically before startup.

## Upgrade Notes

Create a verified backup, then update from the dashboard or start the new
self-host package. Existing database, media, backup, secret, and release-history
volumes are reused. After upgrading, test configured Stripe, PayPal, and email
providers from the dashboard with an owner or another administrator who has
secret-management permission.
