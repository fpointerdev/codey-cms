# CodeY CMS 0.9.11

CodeY CMS 0.9.11 expands the premium builder and completes the live product
content path from CodeY generation through CMS editing and public rendering.
It keeps the self-host update process automatic and does not introduce a CMS
version choice for end users.

## Highlights

- Expands the builder registry to 33 elements and 20 qualified section
  patterns, including Image Comparison and Product Showcase.
- Adds upload-first media controls for supported structured collections and
  preserves imported collection items that are beyond the editor's visible
  eight-row window.
- Adds a visual active-product picker for product lists and product-backed
  section patterns, avoiding placeholder or manually entered product slugs.
- Resolves product-list content to live images, prices, availability, and
  purchase actions in both API-driven navigation and server-rendered pages.
- Preserves Product Showcase values through atomic WebsiteSpec import using the
  canonical `PRODUCT_LIST` block while retaining WebsiteSpec version `1.0`.
- Adds storefront hero uploads with previews, optional CTA controls, catalog
  sorting, product-description visibility, and pre-upload validation.
- Keeps storefront settings synchronized after upload, avoids duplicate media
  uploads on later saves, and uses one deterministic sort contract across SSR,
  the products API, attribute filtering, and client navigation.
- Adds focused contract, integration, and three-browser acceptance coverage for
  product patterns, storefront persistence, media reuse, WebsiteSpec import,
  and public product rendering.

## Compatibility

- WebsiteSpec remains at version `1.0`.
- Builder and exported-site acceptance contracts remain at version `1.0`; the
  builder registry version advances additively to `2026-08-11.1`.
- Existing CodeY-generated sites and CodeY CMS `v0.9.10` data remain
  compatible. No existing content is rewritten during upgrade.
- Payment and email provider credentials remain encrypted dashboard settings
  and are not moved into WebsiteSpec or environment files.
- The signed runtime metadata retains the `v0.9.7` automatic-update bootstrap
  floor.

## Database And Environment

This release adds no database migration and no required environment variable.
The packaged runtime still applies the existing migration set automatically.

## Upgrade And Recovery Notes

Create a verified backup, then update from the dashboard or start the new
self-host package. Existing database, media, backup, secret, and release-history
volumes are reused and setup is not repeated.

Pages with valid active product slugs recover live product cards automatically
after upgrade and reload; no republish is required. If an older draft contains
the literal `starter-product` placeholder but that product does not exist on the
site, open the Product List or Product Showcase once, select an active product,
and save. Imported collections with more than eight items require no recovery:
the hidden items remain intact when any visible field is edited.
